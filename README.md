# Django-Nextjs-project

A full stack Django and nextjs hotel booking web app

Preview
[Demo](https://django-frontend-sigma.vercel.app)

```bash
# Backend setup

cd backend

# activate the virtual environment
venv\scripts\activate

# install dependencies
pip install -r requirements.txt

# To run the backend but make sure you run on port "" 8080 ""

python manage.py runserver 8080

# FRONTEND SETUP
# in a new terminal
cd frontend

# Install dependencies
npm install

# To run the frontend
npm run dev  # also make sure it runs on either port 3000 or 3001
```
